# Complete DAX Measures Dictionary

This document provides the complete DAX (Data Analysis Expressions) calculation dictionary for the Bluestock Mutual Fund Analytics Power BI model. All measures are written in standard DAX format with complete error handling, dynamic filtering, formatting metadata, and inline comments.

---

## 1. Core Executive KPIs

### `Total AUM`
- **Description**: Total Assets Under Management across all active mutual fund schemes in Crores INR.
- **Display Format**: `Currency` (`₹#,##0.00 Cr`)

```dax
Total AUM = 
VAR RawAUM = SUM(Dim_SchemePerformance[aum_crore])
RETURN
IF(
    ISBLANK(RawAUM),
    0,
    RawAUM
)
```

---

### `Total Schemes`
- **Description**: Distinct count of active mutual fund schemes tracked in the master table.
- **Display Format**: `Whole Number` (`#,##0`)

```dax
Total Schemes = 
DISTINCTCOUNT(Dim_FundMaster[amfi_code])
```

---

### `Total Investors`
- **Description**: Count of distinct unique investor IDs across transaction records.
- **Display Format**: `Whole Number` (`#,##0`)

```dax
Total Investors = 
DISTINCTCOUNT(Fact_InvestorTransactions[investor_id])
```

---

### `Total Investment`
- **Description**: Total aggregate investment capital across both SIP and Lumpsum transactions in INR.
- **Display Format**: `Currency` (`₹#,##0.00`)

```dax
Total Investment = 
VAR TotalAmount = SUM(Fact_InvestorTransactions[amount_inr])
RETURN
COALESCE(TotalAmount, 0)
```

---

### `Total SIP`
- **Description**: Total aggregate capital committed specifically via Systematic Investment Plan (SIP) transactions.
- **Display Format**: `Currency` (`₹#,##0.00`)

```dax
Total SIP = 
CALCULATE(
    SUM(Fact_InvestorTransactions[amount_inr]),
    KEEPFILTERS(Fact_InvestorTransactions[transaction_type] = "SIP")
)
```

---

### `Average NAV`
- **Description**: Arithmetic mean Net Asset Value (NAV) per unit across historical pricing records.
- **Display Format**: `Decimal` (`₹#,##0.00`)

```dax
Average NAV = 
AVERAGE(Fact_NAVHistory[nav])
```

## 2. Performance Metrics

### `CAGR (3Y)`
- **Description**: Average 3-Year Compound Annual Growth Rate across selected schemes.
- **Display Format**: `Percentage` (`0.00%`)

```dax
CAGR = 
VAR AvgCAGR = AVERAGE(Dim_SchemePerformance[return_3yr_pct])
RETURN
DIVIDE(AvgCAGR, 100, 0)
```

---

### `Sharpe Ratio`
- **Description**: Average annualized Sharpe ratio measuring excess return per unit of total risk ($R_f = 6.5\%$).
- **Display Format**: `Decimal Number` (`0.00`)

```dax
Sharpe = 
VAR RawSharpe = AVERAGE(Fact_RiskAnalytics[sharpe_ratio])
RETURN
COALESCE(RawSharpe, 0)
```

---

### `Sortino Ratio`
- **Description**: Average Sortino ratio measuring excess return relative strictly to downside volatility.
- **Display Format**: `Decimal Number` (`0.00`)

```dax
Sortino = 
VAR RawSortino = AVERAGE(Fact_RiskAnalytics[sortino_ratio])
RETURN
COALESCE(RawSortino, 0)
```

---

### `Alpha`
- **Description**: Annualized excess return generated by the scheme relative to its benchmark index.
- **Display Format**: `Percentage` (`0.00%`)

```dax
Alpha = 
VAR AvgAlpha = AVERAGE(Dim_SchemePerformance[alpha])
RETURN
DIVIDE(AvgAlpha, 100, 0)
```

---

### `Beta`
- **Description**: Systematic market sensitivity coefficient relative to benchmark index ($1.0 = \text{market risk}$).
- **Display Format**: `Decimal Number` (`0.00`)

```dax
Beta = 
VAR AvgBeta = AVERAGE(Dim_SchemePerformance[beta])
RETURN
COALESCE(AvgBeta, 1.0)
```

---

### `Tracking Error`
- **Description**: Exposes the pre-computed annualized tracking error / active risk volatility percentage from scheme performance.
- **Display Format**: `Percentage` (`0.00%`)

```dax
Tracking Error = 
VAR AvgTE = AVERAGE(Dim_SchemePerformance[std_dev_ann_pct])
RETURN
DIVIDE(AvgTE, 100, 0)
```

---

### `Max Drawdown`
- **Description**: Maximum peak-to-trough percentage decline experienced over the historical observation period.
- **Display Format**: `Percentage` (`0.00%`)

```dax
Max Drawdown = 
VAR MinDrawdown = MIN(Dim_SchemePerformance[max_drawdown_pct])
RETURN
DIVIDE(MinDrawdown, 100, 0)
```

## 3. Risk Analytics

### `VaR 95`
- **Description**: 95% Historical Value at Risk, representing the daily return loss threshold at the 5th percentile.
- **Display Format**: `Percentage` (`0.00%`)

```dax
VaR 95 = 
VAR RawVaR = AVERAGE(Fact_RiskAnalytics[var_95])
RETURN
COALESCE(RawVaR, 0)
```

---

### `CVaR 95`
- **Description**: 95% Conditional Value at Risk (Expected Shortfall), measuring average tail-loss return below VaR 95.
- **Display Format**: `Percentage` (`0.00%`)

```dax
CVaR 95 = 
VAR RawCVaR = AVERAGE(Fact_RiskAnalytics[cvar_95])
RETURN
COALESCE(RawCVaR, 0)
```

---

### `HHI Score`
- **Description**: Herfindahl-Hirschman Index measuring AMC market share AUM concentration ($0 \text{ to } 1$).
- **Display Format**: `Decimal Number` (`0.0000`)

```dax
HHI = 
VAR TotalMarketAUM = CALCULATE(SUM(Fact_AUMByFundHouse[aum_crore]), ALL(Fact_AUMByFundHouse[fund_house]))
VAR AMCShares = 
    ADDCOLUMNS(
        VALUES(Fact_AUMByFundHouse[fund_house]),
        "ShareSq", POWER(DIVIDE(CALCULATE(SUM(Fact_AUMByFundHouse[aum_crore])), TotalMarketAUM, 0), 2)
    )
RETURN
SUMX(AMCShares, [ShareSq])
```

## 4. Investor & Retention Metrics

### `At Risk Investors`
- **Description**: Count of distinct investors whose consecutive SIP payment gap or elapsed days exceeds 35 days.
- **Display Format**: `Whole Number` (`#,##0`)

```dax
At Risk Investors = 
VAR Threshold = 35
VAR MaxDatasetDate = MAX(Fact_InvestorTransactions[transaction_date])
VAR AtRiskList = 
    FILTER(
        VALUES(Fact_InvestorTransactions[investor_id]),
        VAR LastSIPDate = 
            CALCULATE(
                MAX(Fact_InvestorTransactions[transaction_date]),
                Fact_InvestorTransactions[transaction_type] = "SIP"
            )
        VAR DaysElapsed = DATEDIFF(LastSIPDate, MaxDatasetDate, DAY)
        RETURN DaysElapsed > Threshold
    )
RETURN
COUNTROWS(AtRiskList)
```

---

### `At Risk Rate`
- **Description**: Percentage of total SIP investors flagged as At-Risk due to payment gaps > 35 days.
- **Display Format**: `Percentage` (`0.00%`)

```dax
At Risk Rate = 
VAR TotalSIPInvestors = 
    CALCULATE(
        DISTINCTCOUNT(Fact_InvestorTransactions[investor_id]),
        Fact_InvestorTransactions[transaction_type] = "SIP"
    )
RETURN
DIVIDE([At Risk Investors], TotalSIPInvestors, 0)
```
